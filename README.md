# AI Innovation Youth 2026 Competition Platform

## Overview
This repository contains the full‑stack implementation of the competition platform.

- **Frontend**: Next.js (TypeScript) with Tailwind CSS.
- **Backend**: FastAPI (Python).
- **Database**: PostgreSQL (schema to be added in Phase 1).
- **File Storage**: Private local storage under `storage/`.

The project follows a phased development approach as outlined in the specification.
